# AI-Smart Expense Tracker and Budget Planner — Frontend

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. Add transactions and set a monthly budget.

## Features
- Add/delete income and expense transactions
- Categories and dates
- Income, expenses, balance, budget remaining
- Budget usage bar and simple spending insight
- Saves demo data in browser localStorage

## Important
This starter frontend stores its data in the current browser. It is not connected to the Spring Boot backend yet. Do not enter sensitive financial information.
